# **App Name**: Everframe Gallery

## Core Features:

- User Authentication: Secure user login and authentication flow to protect user data.
- Device Activation: Page to link an Everframe device to the user account, ensuring only authorized devices can display the uploaded images.
- Drag and Drop Image Upload: Users can easily upload images to cloud storage by dragging and dropping them into the designated area.
- AI-Powered Image Transformation: Leverage Gemini Pro to transform uploaded images into unique abstract art variations, providing multiple options (random prompts) per image.
- Abstract Art Preview: Before committing, the user sees and selects their favorite variations of the abstract art generated using the tool from their original image.
- Image Management: Gallery view to view, rename, and delete selected abstract art for display on Everframe devices.
- Image Selection for Display: Users can curate images by selecting or deselecting them for display on their Everframe, including default preselection of images after the abstract transformation.

## Style Guidelines:

- Primary color: Soft sage green (#B2BEB5) to align with earthy tones and create a calming atmosphere.
- Background color: Light beige (#F5F5DC) to maintain a minimalist and neutral canvas.
- Accent color: Off-white (#FAF9F6) to provide clean highlights and visual clarity.
- Body and headline font: 'PT Sans' for a clean, modern sans-serif feel, suitable for all text.
- Use simple, outlined icons for image management actions (upload, delete, rename) to keep the UI clean.
- Employ a minimalist design with ample whitespace to focus on the images. Use a grid layout for the gallery view to provide a structured and clean presentation.
- Subtle fade-in animations on image upload and transformations to provide gentle feedback.
